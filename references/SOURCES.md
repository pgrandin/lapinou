# Imported STEP references

Retrieved 2026-09-29. The generator imports the two electronics STEP files below, plus the photo-derived LED puck generated by `generate_puck.py`. Unused Pi 5 and camera-wide research downloads are excluded from this repository.

## Raspberry Pi 3 Model B+

Author: Anson Biggs / MisterBiggs. Simplified reference solid, MIT licence; the downloaded licence is retained in `references/raspberry-pi-3b-plus/LICENSE`.

Creator's project:

https://gitlab.com/MisterBiggs/MyModels/tree/master/Rough%20Pi%20Model

Pinned STEP download used:

https://gitlab.com/MisterBiggs/MyModels/raw/0e57323325c75e175542afb2fc1963708e6ec549/Rough%20Pi%20Model/Rough%20Pi%20Model.step?inline=false

Local file:

references/raspberry-pi-3b-plus/raspberry-pi-3b-plus.step

The source coordinate system has PCB width along X, thickness along Y and length along Z. Mounting-hole axes are at X = 3.5/52.5 and Z = 23.5/81.5 mm, diameter 2.75 mm. The generator rotates and translates this solid without scaling.

Official drawing used to verify the 85 × 56 mm board outline and 58 × 49 mm mounting pattern:

https://datasheets.raspberrypi.com/rpi3/raspberry-pi-3-b-plus-mechanical-drawing.pdf

https://pip.raspberrypi.com/categories/532

## Camera Module 3 standard

Publisher: Raspberry Pi. The imported standard model is retained from the original manufacturer archive; this project's code does not relicense the reference model.

https://pip.raspberrypi.com/categories/1207-design-files

https://pip-assets.raspberrypi.com/categories/1207-design-files/documents/RP-008154-DS-1-camera-module-3-step.zip

Local imported file:

references/camera-module-3-step/Camera_module_3_std_model_simple.stp

The source PCB has mounting holes at X = 2/14.5 and Y = 2/23 mm, diameter 2.2 mm. The lens points along negative Z. The assembly rotates this direction to positive X and places the model's front lens extremity at X = 0. This is a mechanical distance datum, not a measured optical principal plane. No scaling is applied.

Mechanical drawing and FoV reference:

https://datasheets.raspberrypi.com/camera/camera-module-3-standard-mechanical-drawing.pdf

https://www.raspberrypi.com/products/camera-module-3/

## CAD tooling

CadQuery 2.6.1 imports both models using `cq.importers.importStep` and exports true STEP solids and a named assembly. No electronics meshes are converted to STEP.

https://cadquery.readthedocs.io/en/latest/importexport.html
